GitHub Pages 部署說明

簡單三步驟即可將此看板免費上線發表

步驟一：建立 GitHub 儲存庫 (Repository) 登入 GitHub，點選 New Repository，名稱可設為 taiwan-weather-dashboard，設定為 Public。
步驟二：上傳程式碼檔案 將此完整 HTML 原始碼儲存為 index.html，並上傳 (Add file -> Upload files) 至該儲存庫的主分支 (main)。
步驟三：開啟 GitHub Pages 前往 Repository 的 Settings ➔ Pages 頁面，在 Source 選擇 Deploy from a branch，Branch 選擇 main / root，按 Save 保存。稍等約 1 分鐘即可取得網址！
